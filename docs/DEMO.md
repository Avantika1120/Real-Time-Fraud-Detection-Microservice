# Demo walkthrough

## 1. Train a local model artifact

Place the ULB/Kaggle `creditcard.csv` dataset in `data/`, then run:

```bash
pip install -r requirements.txt
python train.py --data data/creditcard.csv --output artifacts/fraud_model.joblib
```

The script prints evaluation metrics and saves the estimator, threshold, and feature contract.

## 2. Start the API

```bash
uvicorn app.main:app --reload
```

Open Swagger at `http://localhost:8000/docs`.

## 3. Check readiness

```bash
curl http://localhost:8000/health
curl http://localhost:8000/model-info
```

## 4. Score a transaction

Use the complete feature set returned by `/model-info`:

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"features":{"Time":406.0,"V1":-2.312,"V2":1.952,"V3":-1.609,"Amount":0.0}}'
```

The API returns a probability, binary decision, and threshold. The short payload above is illustrative; a trained artifact requires the full saved feature contract.

## Docker demo

```bash
docker build -t fraud-detection-api .
docker run -p 8000:8000 -v "$(pwd)/artifacts:/app/artifacts" fraud-detection-api
```

`demo.svg` is an illustrative API preview, not evidence for a specific ROC-AUC result. Evaluation values are generated by `train.py` from the chosen dataset/configuration.
